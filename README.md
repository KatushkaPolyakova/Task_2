# Тестирование API Stellar Burgers

## Реализованные сценарии

### Создание пользователя
- создать уникального пользователя;
- создать пользователя, который уже зарегистрирован;
- создать пользователя и не заполнить одно из обязательных полей.

### Логин пользователя
- вход под существующим пользователем;
- вход с неверным логином или паролем.

### Изменение данных пользователя
- изменение данных(любое поле) авторизованного пользователя
- изменение данных(любое поле) неавторизованного пользователя

### Создание заказа
- создать заказ с авторизацией;
- создать заказ без авторизации;
- создать заказ с ингредиентами;
- создать заказ без ингредиентов;
- создать заказ с неверным хешем ингредиентов.
  
### Получение заказов пользователя
- получить заказы  авторизованного пользователя;
- получить заказы  неавторизованного пользователя

---

## Запуск автотестов

### Установка зависимостей

- pip install -r requirements.txt

### Генерация отчета

- pytest --alluredir=allure_results
- allure serve allure_results
